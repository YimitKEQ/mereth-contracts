# Contracts for Mereth

Player-to-player contracts for [Mereth Roleplay](https://mereth.net), a serious-roleplay
Skyrim server running on [SkyMP](https://github.com/skyrim-multiplayer/skymp).

One player posts work, another takes it, the server moves the septims and keeps the record.
No arbitration, no staff queue, no NPCs. When somebody cannot pay, that becomes a debt note
other players can read.

**Read it: https://yimitkeq.github.io/mereth-contracts/**

Written in TypeScript against the SkyMP gamemode API. Server-authoritative, and delivered to
players at runtime, so nobody installs anything.
